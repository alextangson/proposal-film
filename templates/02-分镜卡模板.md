# 模板 ②：分镜卡 + 人设卡

**怎么用**：把模板 ① 聊出来的素材清单和章节方案，连同下面"给 AI 的话"一起发给任何 AI，让它按这个格式写分镜卡和人设卡。也可以自己照着表格填。写好的分镜卡就是后面每一步（出首帧、生成视频、剪辑）的说明书。

---

## 一、分镜卡

一行是一段，**时间按歌曲时间写**，章节跟着歌的段落走。"画面"一栏用 **→** 连起一个镜头里接连发生的事：箭头表示画面在镜头里自己变过去（一只手、一个物件、一道光把观众带到下一个画面），不是后期加的特效。

| 时间 | 章节 | 画面（→ 表示镜头内完成的转场） |
|---|---|---|
| 0:00–0:12 | 序 | 米色纸。笔画出三个格子 → 依次印出"阿舟和老周 / 老周和他女朋友 / 老周女朋友和小满" → 一根红线一笔串起四个人 |
| 0:12–0:45 | 一·相遇 | 红线浮起 → 落到生日会的桌游桌上，变成一张黄色卡牌 → 阿舟又输了，小满笑出声 → 推近她笑弯的眼睛 → 眼睛里映着的灯光变成便利店门口的灯 → 下雨，两人躲雨 → **小满转头说"要不我们试试"** → 阿舟愣住，然后笑开 |
| 0:45–1:20 | 二·热恋 | 小满撑开一把透明伞 → 伞面转一圈，伞外已经是厨房 → 一起包饺子，阿舟的全部露馅 → 小满拿手机拍他 → 画面定格成照片 → 照片像相册一样滑走，下一张活过来（猫、海边、游乐园） |
| 1:20–1:42 | 三·难的时候 | 相册里最后一张照片变暗 → 深夜书桌，小满在台灯下复习，眼睛发红 → 手机屏幕里阿舟突然学企鹅走路 → 她没忍住笑出来，边笑边擦眼睛 → 台灯熄灭，黑一拍（音乐不停） |
| 1:42–2:20 | 四·最高点 | 歌最响的地方：一束光从黑里亮起 → 两人在不同城市同时伸手 → 指尖碰到画面中线，两个画面像拉链一样合拢，手牵上 → 一个长镜头走过一起去过的地方 |
| 2:20–2:40 | 五·真实照片 | 白光变成纸 → 真实合照一格格印到漫画页上，每张卡在拍子上 |
| 2:40–3:05 | 六·现在 | 橘猫跳上沙发 → 两人窝着看电视 → 阿舟又学企鹅走路 → 小满笑 → **他停下来，认真地看着她** |
| 3:05–结束 | 终 | 米色纸，红线画出一把小伞 → **Will you · marry · me?** 一个词一个词出现，问号落在最后一个音上 → 停住不动，交给现场的你 |

**写的时候检查**：
- 每一行都能追溯到素材清单里的一件真事吗？编出来的删掉。
- 每个 → 都有一个看得见的东西带过去吗？"突然切到"不算。
- 情绪最重的画面（加粗的那几处）是近景吗？一张脸一个镜头。
- "回头看她"这类画面，两人的站位对吗？她必须在他回头的方向。
- 结尾有没有留够静止时间，给真人开口？

## 二、镜头卡（要用 AI 生成视频时再写）

分镜卡里的一行通常要拆成几个镜头。每个镜头 4–15 秒，写首帧、尾帧和镜头里发生的事；**上一个镜头的尾帧就是下一个镜头的首帧**，这样拼起来就是一镜到底。

| 编号 | 时长 | 首帧（一句话） | 尾帧（一句话） | 镜头里发生什么 |
|---|---|---|---|---|
| C03 | 6 秒 | 生日会桌游桌，近景，阿舟举着一张黄色卡牌一脸绝望 | 小满笑弯的眼睛特写 | 阿舟摊牌认输，镜头从牌移到对面笑出声的小满，慢慢推近她的眼睛 |
| C04 | 5 秒 | 小满笑弯的眼睛特写（= C03 尾帧） | 便利店门口，雨夜，两人并排躲雨 | 她眼里映着的灯光放大成便利店门口的灯，镜头退出来，外面在下雨 |

提示词开头固定写：`One continuous shot with no cuts; the camera move carries us from the first frame to the last frame.`，结尾附上画风和人设的那一段固定文字。一个镜头只做一件事。

## 三、人设卡

每次让 AI 画人，都把这张卡一起发过去，保证全片人物长得一样。**写清"是什么"，也写清"不是什么"**——AI 最常见的错是把人画胖或画矮。

```text
人物（画成卡通脸，不要写实）：
- 阿舟（男主）：二十多岁，东亚男生，高而瘦——腿长、腰细，比小满高一个头。短黑发，笑起来眼睛眯成线，常戴一副圆框眼镜。不胖、不壮。
- 小满（女主）：二十多岁，东亚女生，个子小，齐肩短发带一点内扣，圆脸，大眼睛。常穿米色针织开衫。
- 老周（介绍人，配角）：微胖但不算胖，圆脸，寸头。比阿舟壮一点，但差得不多。
所有人在每张图里都要认得出、保持一致。图里不要出现文字、字母、水印。
```

```text
画风：
像"漫画活过来"的 3D 动画：3D 立体的人物配上平涂质感，脸、头发、衣褶上有手绘的黑色线条，阴影和天空里有清楚的网点，边缘有一点点印刷错版的红蓝色边，暖橘和淡紫的黄昏色调。只借这种质感，不要复制任何现有角色、服装或标志。
```

**人设卡的小经验**：
- 身材一定要写，而且要让本人确认（"我没那么胖"是最常见的返工原因）。
- 写一个标志物（眼镜、项链、发夹），换场景时最容易靠它认出是同一个人。
- 同一场戏里衣服要一样，换场景再换衣服；写进分镜卡里。
- 真人照片只当参考给 AI 看，不要放进视频画面里；真实照片放在"真实照片"那一段单独出现。

## 给 AI 的话（复制这段 + 你的素材清单）

```text
下面是我们的故事素材清单和章节方案。请按这个格式帮我写：
1. 分镜卡：表格三列「时间 / 章节 / 画面」。时间按歌曲时间写；"画面"一栏用"→"连接一个镜头里接连发生的事，每个"→"都要有一个看得见的物件、动作或光把画面带过去，不要用后期特效。情绪最重的画面加粗，并且用近景。只用我素材里的真事，不要编。
2. 人设卡：每个出场人物写年龄段、身材（写清"不是什么"）、发型、一个标志物、常穿的衣服；注明"卡通脸，不要写实"。
3. 写完后自查：每一行能不能对应到素材清单里的一件真事？视线和站位对不对？结尾有没有留静止时间？把自查结果列在最后。

我的素材清单和章节方案：
（粘贴在这里）
```
