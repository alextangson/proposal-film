# 故事、转场与结尾

## 章节贴着歌排

- 先测歌：BPM 和小节重拍（看频谱变化找小节起点）、逐小节响度、歌词时间（Whisper 之类的语音识别）。案例里那首歌的段落是：前奏轻 → 主歌 → 副歌 → 主歌变轻 → 副歌 → 全曲最响的一段 → 突然变轻的尾段 → 渐弱。
- 每个段落对应一个章节：主歌讲故事，副歌放热恋的快节奏，变轻的主歌放低谷（异地），**最响的一段给重逢**，突然变轻的那一拍给"梦醒"和最安静的情绪，最后一个音给 "me?"。
- 关键动作落在重拍上：手扣上、梦醒、问号出现。误差控制在一帧以内。
- **不要在歌里静音。** 设计成"屏住呼吸"的 1.4 秒静音，被听成了卡顿。要停顿就用画面停（黑一拍），音乐继续。
- 不要剪歌、不要循环前奏凑时长；素材多了就加速（单个镜头 0.8–1.4 倍）或删情节。

## 主线结构（案例用的，可以换内容不换骨架）

1. 纸面开场：人物关系图，红线把两个人串起来。
2. 相遇 → 确定关系那天。
3. 热恋日常（轻快，可以用皮克斯风）。
4. 低谷（异地），用一个真实的治愈动作收住。
5. 重逢：一个长镜头走过一起去过的地方。
6. 真实照片段。
7. 现在的日常 → 梦 → 梦醒 → 他变认真。
8. 结尾卡，长时间静止。

## 转场设计

总原则：**每个接缝都有一个画面里的动作或物件把观众带过去。** 首尾帧接力：上一个镜头的最后一帧就是下一个镜头的第一帧，转场动作写进镜头的提示词里，由视频模型生成；剪辑时直接硬接。

案例里做成功的例子：
- 她眼睛里映着的光 → 推进去 → 变成舞台聚光灯 → 镜头往下摇到台下。
- 扶手上两只手碰到 → 镜头拉开 → 已经在商场里牵着手走。
- 她把球抛上去 → 镜头跟着球升进光里 → 落下来时画风变成皮克斯风。
- 一记扣杀把球打出窗外 → 球飞过山林 → 落在他瘫着的台阶边。
- 一道光从握紧的两只手中间劈下 → 画面裂成两座城市。
- 分屏中线：两只手同时碰到中线，光碎成光点，两个世界像拉链一样合拢。
- 一阵风吹过花瓣，她跑开，一盏灯笼划过镜头，划过去就到了下一个城市。
- 她转圈，头发和衣摆甩过镜头，甩过去衣服变成了当地的服饰，接着她跳到他背上。
- 背着走向夕阳，地平线不动，湖面的倒影变成下一座城市的灯火。
- 轻轨的车灯照满画面 → 白光变成纸。
- 镜头从锅边移到窗外，天从黄昏变成夜晚，再移回来时两人已经在沙发上。

被否掉的：
- 漫画格撞碎、粒子爆炸。
- 后期加的白闪（快门这种故事里本来就有的除外）。
- 物体从镜头前扫过（大灰柜子之类）。
- **两个不同场景或画风互相融合**：两个人的脸和项链叠在一起，很吓人。要换画风或换场景，就先统一房间和人物，让光线或镜头运动来带。

蒙太奇要有一个能看懂的概念。案例的做法是"他手机相册里的她"：他举起手机拍下她 → 画面定格成照片 → 照片像相册一样滑走 → 下一张照片活过来 → 最后一张照片活过来，接回主线。

## 情绪戏

- 近景，正反打，一张脸一个镜头。同一个机位的"前、后"两张首帧做首尾帧（比如鬼脸 → 认真），变化才看得清。
- 情绪镜头保持原速，给够时间，不要被节奏压短。
- **梦 → 现实**：梦里两人转身摆成真实婚纱照的姿势，然后对齐叠化成满屏的真实照片（先量好两人的位置，再缩放对齐）。不要放回纸面上变成一张小照片。照片停住以后，柔化、变亮、消散，接梦醒的特写。

## 结尾卡

- 一张有层次的卡：纸纹 → 淡淡的网点光晕 → 双线边框 → 主图（她喜欢的花）→ 贯穿物件收尾（红线在花茎上打成蝴蝶结，尾巴划过字下方收成小卷）→ 大号手写体两行 → 小号日期。用 PIL 之类的库逐帧画出来，见 `production.md` 第 4 节。
- 动画顺序：线条从花茎底部开始画（不要从画面边上拖线进来）→ 上墨、印网点 → 打结 → 字一个词一个词卡拍出现，问号落在最后一个音上 → 日期 → 完全静止。
- 结尾卡要静止足够久，让真人求婚时画面不变，也不会弹出播放器界面。
- 先出 2–3 个排版方案给用户挑，再做动画。
