# 匿名案例：一部做完的求婚微电影

人名、日期、城市和私人情节都已经去掉或换成泛称，只留下做片时的判断和教训。

## 基本情况

- 男方求婚。两人经朋友介绍认识，有过几年异地（下文叫城市 A 和城市 B）。婚纱照已经拍了，还没正式求婚。
- 在家里电视上放，横屏；配乐是一首约 3 分 17 秒的英文情歌，整首用；她喜欢的一种花当暗号；男方的招牌动作是做鬼脸逗她。
- 工具：Claude 负责访谈、分镜和提示词；ChatGPT（Codex）生成首帧；fal 上的 Seedance 2.5 做首尾帧接力；Topaz 超分；ElevenLabs 生成音效。全片约 123 美元。她答应了。

## 每一版被否了什么，怎么解决

| 版本 | 做了什么 | 反馈 | 教训 |
|---|---|---|---|
| v1 | 80 秒，平行宇宙加四个古代宇宙，配独白 | 方向可以 | 先给一个能反应的方向，比空问需求快 |
| v2–v4 | 改成"按画风切换宇宙"，再改成真实经历 | "独白太尬""客厅照片太尬""8 秒一换太慢" | 不写独白；真实生活空间不进 AI 参考 |
| 画风样图 | 4 种画风 → 用用户的截图当参考重出 | 选了"漫画活过来"风加皮克斯风 | 用户的截图比形容词准 |
| 480p 草稿 | 镜头按顺序接起来 | "镜头之间没关联""没音乐""没片尾" | 草稿也要带音乐和结尾，否则用户没法判断 |
| 动态分镜 | 加上音乐和后期转场 | "转场是后期加的，不连贯"；"闪一下某个画面很奇怪"；"照片段太简单" | 转场要在镜头里完成 → 改用首尾帧接力 |
| 照片长廊 | 3D 拍立得长廊 | "low，和整体风格差点意思" | 真实照片用纸面印刷漫画页来放，和画风统一 |
| 首尾帧接力 + 纸面漫画页 | 转场在镜头里完成 | 基本认可；开头"漫画格撞碎"出戏 | 粒子、撞碎这类特效出戏 → 改成红线串起来 |
| 98 秒 | 前奏循环拼接 | "很多情绪没渲染到位，可以做成微电影" | 不要剪歌凑时长，片长就是歌长 |
| v3（整首歌） | 加情节，用整首歌 | 发现用错版本；"音乐 2 分钟卡顿"（是设计的静音）；"沙发转场吓人"；"相册概念看不懂"；结尾字太小 | 剪辑前核对镜头版本；歌里不静音；两个场景不互相融合；蒙太奇要有一个能看懂的概念 |
| v4 | 修好以上问题，结尾 A 版 | "婚纱照那里还是怪，没有做梦和醒来的氛围" | 情绪转折要给够时间和近景 |
| v5 | 梦里摆婚纱照姿势 → 对齐叠化成真实照片 → 近景正反打梦醒 | "还好" | 梦 → 现实用对齐叠化，不要缩成一张小照片 |
| v6 | 超分 + 85 处音效 | "有点电流麦"；"机场回头没往她那边看"；"电影院应该是男生的手先动" | AI 音效要去嗡声；一个镜头只做一件事 |
| v7 | 音效去嗡声、去掉房间底噪；把她挪到另一边修视线；手的戏单独拆成一个镜头 | "机场看的方向还是不对"（她跑到了他前方，空间反了） | 视线问题要按空间关系想，放大到原尺寸看眼睛 |
| 定稿 | 机场改成过肩构图：前景她的背影挥手，中景他在安检口回头看向镜头 | 通过 | — |

## 最终结构（时间 = 歌曲时间）

| 时间 | 段落 |
|---|---|
| 0:00 | 纸面开场：镜头跟着笔走，三格漫画画出"朋友的朋友"这条关系链，红线把两个人串起来 |
| 0:12.8 | 红线浮起变成红绳，系在饭桌下两人的小指上 → 对视 → 推进她眼里的光 → 聚光灯 → 他没看台上，在看她笑 → 扶手上的手 → 她回头说出"要不试一试" |
| 0:46.3（副歌） | 两手扣上 → 一起打球 → 他拍下她噘嘴 → "他手机相册里的她"蒙太奇 → 一记扣杀把球打出窗外 → 山上她把他拽起来 |
| 1:19.7（音乐变轻） | 光劈开双手 → 深夜机场 → 舷窗 → 城市 A / 城市 B 视频分屏 → 雨夜她累到想哭，他做鬼脸把她逗笑 → 到达口和安检口来回加速 → 单程票 → 黑 |
| 2:00.7（最响） | 指尖碰到分屏中线，两手扣上 → 一个长镜头走过一起去过的几个地方（每到一处用风、灯笼、转圈、湖面倒影接到下一处） |
| 2:22 | 白光变成纸 → 真实照片漫画页（卡拍子） |
| 2:36 | 做饭 → 窗外入夜 → 沙发上睡着 → 入梦 → 礼堂 → 转身摆婚纱照姿势 → 叠化成真实婚纱照 → 消散 |
| 2:58.1（突然变轻） | 梦醒近景：睁眼 → 鬼脸 → 她笑 → 他收起鬼脸变认真 → 她眼里泛泪 |
| 3:08 | 翻页 → 红线画出她喜欢的花、系蝴蝶结 → Will · you · marry · me?（问号落在最后一个音上）→ 静止几分钟，真人接上 |

## 这部片最值钱的三个决定

1. **低谷和结尾来自同一个真实习惯。** 他总做鬼脸逗她：异地时用它治愈，结尾"最后一次不开玩笑"收起鬼脸变认真。这条线是访谈里问"那段时间你是怎么让她开心的"问出来的，不是编的。
2. **最响的一段给重逢。** 歌的结构决定了情绪往哪放；高潮留给"不再异地"，最安静的那一拍留给梦醒。
3. **结尾不说话。** 片子停在一张静止的卡上，剩下的交给现场的人。
